# HouseRules

A shared-apartment web app that helps a new roommate discover the unwritten household rules, see where housemates disagree, agree on compromises, and publish a printable house charter.

Built with plain HTML, CSS and JavaScript (no build step). Data is stored in the browser via localStorage.

## Run locally
Open `index.html` in a browser.

## Deploy
Import this repository in Vercel (Framework preset: Other, no build command).
